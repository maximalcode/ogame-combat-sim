# AGENTS.md

The working notes for this repository live in one file: [CLAUDE.md](CLAUDE.md).
Read that. It is the whole brief, and it is the brief for every agent
regardless of which tool you are — nothing here is Claude-specific.

There is deliberately no second copy. This file *was* one until it drifted: it
froze before `combat-ogame-api` existed and went on asserting that
`BuiltinLifeformTechs` was the only implementation of `LifeformTechTable` after
`ServerDataLifeformTechs` had already shipped. `CLAUDE.md`'s own opening rule —
if a claim and the code disagree, the code is right — cannot hold in a file
nobody updates because it looks like a copy of the one they did update.

Keep it a pointer. If you need to record something, record it in `CLAUDE.md`.
