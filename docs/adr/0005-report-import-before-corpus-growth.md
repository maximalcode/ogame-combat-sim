# Separate report import from corpus growth

The first agent-ready report task will parse user-provided combat and espionage
reports into sanitized simulation inputs and regression fixtures. Building a
broad public corpus remains incremental work driven by available reports and a
visible coverage matrix, so parser delivery does not depend on obtaining every
desired battle category upfront. Reports from public archives such as OGMem may
be inspected manually to find discrepancies, but they are committed as fixtures
only when the uploader has consented and identifying data has been removed.
